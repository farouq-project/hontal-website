## Before uploading

1. **Compress** — use TinyPNG, Squoosh, or ImageOptim. Target under 500KB per screenshot.
2. **Blur** — mask customer names, phone numbers, and addresses using Figma, Photoshop, or any photo editor.
3. **Authentic** — do not fake or mock data beyond blurring. The UI must show real Hontal screens.
4. **Format** — PNG or WebP. WebP preferred for better compression.
